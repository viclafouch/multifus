# @multifus/runes

The rune weights of Dofus Retro, as data: the families, the stats of each family,
the weight of every stat, and one formatter.

```ts
import { RUNE_WEIGHTS, formatWeight } from '@multifus/runes'
```

It carries no text and no layout. Screen wording lives in the catalogue of each
application, and every stat is keyed by an identifier this package owns.
